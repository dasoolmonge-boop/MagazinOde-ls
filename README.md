# Telegram-бот магазина Kuzel

Бот и Mini App для Telegram на Python без сторонних библиотек. Mini App показывает каталог, фильтры категорий, карточки товаров, корзину и форму заказа. Заказ отправляется менеджеру в Telegram. В боте остаются быстрый каталог и простая форма заявки.

## Запуск

1. Создайте нового бота через официальный `@BotFather`. Токен, опубликованный в переписке, следует отозвать и заменить новым.
2. Установите Python 3.10 или новее.
3. Для локального просмотра Mini App запустите сервер из папки проекта:

   ```powershell
   python -m http.server 8000
   ```

   Откройте `http://localhost:8000/miniapp/` в браузере. Каталог, фильтры, корзина и демо-оформление доступны без токена. Вне Telegram заказ никуда не отправляется и не сохраняется.

4. Опубликуйте проект в GitHub. Workflow `.github/workflows/pages.yml` развернёт Mini App и публичный каталог на GitHub Pages при push в `main` или `master`. В репозитории откройте **Settings → Pages** и выберите источник **GitHub Actions**. После успешного запуска workflow адрес будет `https://<владелец>.github.io/<репозиторий>/miniapp/`.

5. Установите переменные окружения бота из `.env.example` (сам файл `.env` бот автоматически не читает). `WEBAPP_URL` должен указывать на опубликованный HTTPS-адрес. Для PowerShell текущего сеанса:

   ```powershell
   $env:TELEGRAM_BOT_TOKEN = "новый_токен"
   $env:ADMIN_CHAT_ID = "telegram_chat_id_менеджера"
   $env:WEBAPP_URL = "https://ваш-домен.example/miniapp/"
   python bot.py
   ```

6. Менеджер должен открыть бота и отправить `/start`; его chat ID можно посмотреть у `@userinfobot`. Укажите ID в `ADMIN_CHAT_ID` и перезапустите процесс.
7. Запустите бота командой `python bot.py`. Откройте чат с ботом в Telegram и нажмите `/start`, затем «Открыть магазин».
8. Замените демонстрационные товары, цены, условия доставки, оплаты и контакт в `catalog.json` перед запуском для покупателей.

## Каталог

Пример формата:

```json
{
  "categories": [
    {
      "name": "Платья",
      "products": [
        {"name": "Название модели", "price": "12 000 ₽", "description": "Размеры 42–48", "image": "../images/model-01.jpg"}
      ]
    }
  ],
  "delivery": "Доставка по ...; оплата ...",
  "contact": "Связь: @username"
}
```

Поле `image` необязательно. Фотографии каталога Mini App лежат в `miniapp/images/`; путь в каталоге указывается относительно страницы, например `images/model-01.jpg`. Фотографию, сохранённую в корне проекта, можно подключить относительным путём `../имя-файла.jpg`. Если фотографии у товара нет, карточка покажет нейтральную заглушку.

E-mail-форма подписки отправляет адрес только при наличии API-адреса в `window.KUZEL_SERVICES.newsletterEndpoint`; без него сайт показывает, что подписка не подключена, и не сохраняет введённую почту. Оформление заказа отправляется Telegram-боту из Mini App. В обычном браузере заказ не сохраняется и не отправляется.

GitHub Pages публикует только статическую витрину и каталог. Сам Telegram-бот нужно держать запущенным на компьютере или развернуть на сервере: GitHub Pages не выполняет Python-процесс. Заказы Mini App передаются менеджеру через Telegram, если задан `ADMIN_CHAT_ID`; иначе покупатель увидит сообщение, что приём заказов настраивается. Платёжная форма не подключена: способ оплаты согласуется с менеджером.

Токен Telegram, отправленный в переписке, следует отозвать через `@BotFather` и заменить новым до запуска.
